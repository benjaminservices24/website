# Premier Construction - Contractor Website

A modern, responsive one-page website for a general construction contractor. This website features a clean design, photo gallery, customer testimonials, and a contact form for quote requests.

## Features

- **Responsive Design**: Looks great on all devices
- **Service Showcase**: Highlight your construction services
- **Photo Gallery**: Display your best work with an elegant gallery
- **Customer Testimonials**: Build trust with potential clients
- **Contact Form**: Easy way for customers to request quotes
- **Modern UI/UX**: Clean and professional design

## Getting Started

1. **Clone the repository**
   ```bash
   git clone [your-repository-url]
   cd [repository-name]
   ```

2. **Open in Browser**
   Simply open the `index.html` file in your web browser to view the website locally.

## Customization

### Content Updates
- **Company Information**: Update the company name, contact details, and address in `index.html`
- **Services**: Modify the services section in `index.html` to match your offerings
- **Images**: Replace the placeholder images in the gallery with your project photos
- **Testimonials**: Add or update customer testimonials in `index.html`

### Styling
- **Colors**: Update the CSS variables in `styles.css` to match your brand colors
- **Fonts**: Change the font family in the `body` section of `styles.css`

### Form Submission
By default, the contact form logs submissions to the console. To process form submissions:

1. Update the form's `action` attribute in `index.html` to point to your form processing script
2. Or, integrate with a form service like Formspree, Netlify Forms, or similar
